# What is it?
This is my personal macOS nav bar app. It has the following features:
 - Audio device I/O selection
 - Media playback controls
 - Hub for frequently used apps
 - Keyboard cleaner

# Why build it?
I got tired of seeing the same duplicate apps on the App Store that cost money for something that can be done in less than a day.

# How do I use it?
You must have Xcode installed on a macOS device. Open the Xcode project file on Xcode, build first (CMD + B), then run.
